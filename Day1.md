# Day 1

## Today I Learned

* A variable is a container that stores data.
* Variables have a name, value, and type.
* int → stores whole numbers (health, coins)
* float → stores decimal numbers (speed)
* string → stores text (player name)
* bool → stores true or false (alive/dead)

## Reflection

**What is a variable?**
A variable stores data that can change while the program runs.

---

*Why do games need variables?*
To store and update player data like health, coins, and score.

---

*Difference between int and float?*
int → whole numbers
float → decimal numbers

---

*What does bool store?*
true or false values

---

*What happens when a variable changes?*
The value updates and affects the program (like health decreasing).

---

**How did I use variables?**

* health → decreases when damage happens
* coins → increases when collecting
* speed → stores movement value
* isAlive → shows if player is alive

---

*What is an expression?*
Used to change values
Example: health = health - damage

---

**What is a loop?**
Repeats code multiple times
Used to apply damage again and again

---

**What is a function?**
A block of code that performs a task
Example: CalculateScore()

---

**Overall Understanding**

* Variables store game data
* Values keep changing during gameplay
* Loops repeat actions
* Functions organize code
* All games depend on variables
